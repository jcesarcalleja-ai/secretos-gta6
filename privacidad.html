Política de privacidad de shorts-factory

Última actualización: 19 de noviembre de 2026.

Quién la usa

shorts-factory es un cliente de escritorio de la API de YouTube que usa exclusivamente el titular del canal Secretos GTA 6, en su propio ordenador. No hay registro de usuarios ni acceso para terceros.

Uso de los Servicios API de YouTube

Esta herramienta usa los Servicios API de YouTube. Al usarla se aceptan las Condiciones del Servicio de YouTube. Se aplica también la Política de Privacidad de Google.

Qué datos usa

  • Token de acceso OAuth de la cuenta de Google del titular, con los permisos youtube.upload y youtube.readonly.
  • Estadísticas públicas de los vídeos propios del canal: visualizaciones, “me gusta” y número de comentarios.

No se recogen datos de otros usuarios ni de otros canales, ni datos personales de espectadores.

Para qué

Para subir los vídeos del propio canal y para medir qué vídeos funcionan mejor. Nada más.

Dónde se guardan y cuánto tiempo

El token y las estadísticas se guardan solo en el ordenador del titular. No se envían a ningún servidor propio ni se venden o ceden a terceros. Para decidir qué temas funcionan mejor, las cifras de los vídeos propios pueden enviarse junto con los guiones a un modelo de IA (API de Anthropic), solo para analizarlas; el token nunca sale del ordenador. Las estadísticas se vuelven a pedir a la API en cada ejecución diaria del programa, de modo que nunca se conservan datos de más de 30 días sin actualizar, como piden las políticas de la API de YouTube.

Cookies

La herramienta no usa cookies ni rastreadores. Esta página tampoco.

Cómo revocar el acceso

El acceso se puede retirar en cualquier momento desde la página de permisos de seguridad de Google. Al hacerlo, y borrando el archivo del token del ordenador, se eliminan todos los datos guardados.
